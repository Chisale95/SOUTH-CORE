# SOUTH-CORE

> **Problem first. Code later.**

SOUTH-CORE is a long-term systems engineering project focused on maintaining continuity of work when normal access to important information is disrupted.

The project is being developed incrementally from real-world problem investigation rather than from a predetermined technology stack.

---

## Current Status

**Phase:** Problem Investigation → First Working Capability

**Current capability under development:**

> **Preserve unfinished work so that work can continue after disruption.**

No large system architecture has been committed yet.

The project is intentionally being built one small, testable capability at a time.

---

# The Problem

Important information can exist without being accessible.

When normal access to information is disrupted, organisations may be forced into slower fallback processes.

That can reduce the amount of work that can be completed during a given period.

When incoming work continues while processing capacity decreases, unfinished work can accumulate.

```text
Information becomes inaccessible
            ↓
Normal processing is disrupted
            ↓
Fallback processes may require more time
            ↓
Processing capacity decreases
            ↓
Some work remains unfinished
            ↓
Backlog increases
